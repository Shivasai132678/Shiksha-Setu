# Demonstrating the weekly outreach decision

Open **index.html** and choose **Open district desk**. The register contains the 12 illustrative records from the assessment. Start with a fresh browser profile for an empty weekly plan.

1. Open **ST012** from the student register. Its baseline attendance is 44% and no previous visits are recorded. Approve a household visit. The field schedule now shows one assignment costing INR 250.
2. Return to the case, select a reported barrier, enter a short example note and record the outcome. Under **Weekly follow-up**, enter week 1, three days present and five eligible days. The register displays 60%, a 16-percentage-point increase over the baseline.
3. Open **ST009**, review the two earlier visits and record the review. This decision adds no household visit. Request a watchlist downgrade with a reason to demonstrate the below-50% safeguard.
4. In **Demo settings**, choose the 240-student capacity scenario. Open **Field schedule** and approve simulated first visits to see the reserve limit and deferred assignments. The assessment and capacity scenarios maintain separate local records.

The browser stores demonstration events on the current device. Offline queuing is simulated. The shared services in the architecture diagram describe the pilot proposal.

## Source and build

The React source lives in src/. To rebuild, run `npm ci` and `npm run build` from this directory. To serve the local build, run `npm start` and open http://127.0.0.1:4174. The prebuilt index also works directly from the extracted directory.
